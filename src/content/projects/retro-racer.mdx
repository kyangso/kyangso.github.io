# Retro Racer

A retro-style pixel racing game inspired by classic SNES Mode7 racers.

## Controls

| Key   | Action     |
| ----- | ---------- |
| W     | Accelerate |
| S     | Brake      |
| A     | Turn Left  |
| D     | Turn Right |
| Enter | Start Race |
