# Retro Racer

A retro-style pixel racing game inspired by classic SNES Mode7 racers.

## About

Retro Racer is a browser-based racing game built for my Astro portfolio website.

The game features:

- Retro pixel-art inspired visuals
- Classic arcade racing controls
- AI opponents
- Ranking system
- Minimap
- Finish line and replay system
- Playable directly in the browser

## Controls

| Key | Action |
|------|---------|
| W | Accelerate |
| S | Brake |
| A | Turn Left |
| D | Turn Right |
